# ADR 007: Discovery & Saved Search Architecture

## Status
Accepted

## Context
Multi-criteria discovery, filter pipelines, search history, and alert subscriptions needed to be added without overloading UI hooks or providers.

## Decision
We introduced a layered discovery architecture:
1. `RecentSearchesService`: Encapsulates browser `localStorage` management for the last 10 search terms with deduplication and deletion support.
2. `SavedSearchesService`: Manages persistent saved search models with configurable alert frequencies (`instant`, `daily`, `weekly`).
3. `DiscoveryController`: Serves as the central orchestration service combining filtering, sorting strategies, history, saved searches, and delegation to `SearchService`.
4. `useSearch`: React UI controller hook limited strictly to UI concerns (debouncing, modal open/close states, input state).

## Consequences
- Keeps `useSearch` hook thin and focused on view concerns.
- Decouples search execution from filter pipelines and history management.
