# ADR 010: Centralized Telemetry & Analytics Platform Architecture

## Status
Accepted

## Context
Cross-cutting telemetry was needed across Search, Notifications, Jobs, Authentication, and Marketplace without duplicating event collection logic in individual UI views or domain services.

## Decision
We established a centralized Telemetry & Analytics architecture:
1. `AnalyticsEvent` Payload Contract: Standardized event structure containing `id`, `category`, `eventName`, `timestamp`, `userId`, `properties`, and `metadata`.
2. `AnalyticsService`: Aggregates telemetry across domain services (Search queries, Notification dispatches, Job executions, Application submissions) into an event buffer.
3. `AnalyticsCollector`: Background worker integration consuming event buffers and persisting aggregated metrics.
4. Domain Dashboards: Thin presentational dashboards consuming aggregated telemetry via `useAnalytics` hooks.

## Consequences
- Decouples event generation from analytics storage and presentation.
- Provides unified operational intelligence for candidates, employers, and administrators.
