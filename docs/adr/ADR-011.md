# ADR 011: AI Productivity Suite Architecture

## Status
Accepted

## Context
AI capabilities (Resume Analysis, AI Job Matching, Interview Preparation) needed to be integrated as higher-level domain services consuming pre-existing Search, Notification, Jobs, and Analytics platforms without modifying their core APIs.

## Decision
We established a decoupled AI Productivity Architecture:
1. `AIServiceContract`: Common interface for AI features specifying input schemas, prompt templates, fallback deterministic providers, and output formatting.
2. `ResumeAnalyzerService`: AI resume scoring service parsing skills, experience, and domain relevance against open job requirements.
3. `AIJobMatcherService`: AI match generator consuming `SearchService` results and applying semantic scoring boosts.
4. `InterviewPrepService`: Interactive mock question and response evaluator.
5. Telemetry & Alerts: All AI execution events emit telemetry via `AnalyticsService` and dispatch complete reports via `NotificationEngine`.

## Consequences
- Guarantees AI services consume established platform infrastructure without code drift.
- Keeps core platform services frozen, stable, and clean.
